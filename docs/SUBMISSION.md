# Submission checklist

Deadline: Sunday 15 Nov 2026, 23:59 Asia/Colombo. We submit by 21:00.

The rules below come from the 2025 Space Apps guides. **Not yet re-checked for 2026:** re-read
<https://www.spaceappschallenge.org/resources/project-submission-guide/> before filling the form.

## Form fields

- [ ] Project name
- [ ] Summary
- [ ] Demo link: a 30-second video **or** up to 7 slides including the title slide. Going over makes us ineligible for global judging
- [ ] Final project link (the public site and the public repository)
- [ ] Detailed description
- [ ] NASA data used: copy from `docs/RESOURCES.md` ("NASA data in the product now")
- [ ] Other data used: copy from `docs/CREDITS.md`
- [ ] AI-use disclosure: copy from `docs/AI_USAGE.md`

## Rules

- [ ] English, with English subtitles on any video
- [ ] Every link opens without a login, password or permission request (test in a private window)
- [ ] NASA data is used **and listed**, or we cannot win a global award
- [ ] AI-generated images or video carry a visible watermark and no NASA logos or insignia (we have none so far)
- [ ] Real NASA imagery is credited on the About page

## Before we submit

- [ ] `npm run check:facts -- --strict` passes (passes on 14 Nov 2026)
- [ ] Make the GitHub repository public (it is private now)
- [ ] Every episode passed `docs/FUN_CHECKLIST.md`
- [ ] The site is deployed at a public URL and tested on a laptop and a phone
- [ ] The repository is public with the MIT licence (now private: ViduraMC/Zorvex-Space-App-Challenge)
- [ ] Sinhala and Tamil text reviewed by speakers

Judging criteria: Impact, Creativity, Validity, Relevance, Presentation.
